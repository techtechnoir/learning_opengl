To make it run on your workbench, you may need to put glad.h in your include (if you do not have yet).
Make sure you have GLFW library too.

1. git clone https://github.com/techtechnoir/learning_opengl.git
2. cd learning_opengl/
3. mkdir build && cd build
4. cmake ..
5. cmake --build .
6. ./OpenGLTriangle
